# EFATA Financials

The repo is **public** and production auto-deploys from `main`. Read `docs/DEPLOY.md` before a
commit, push or deploy: it holds the data rules (no member data in git) and the Coolify setup.
The root-level guides (QUICKSTART, COOLIFY_DEPLOYMENT, ...) predate it; where they disagree,
`docs/DEPLOY.md` wins.

To check a change or run the app against a copy of the data, see `docs/TESTING.md`.
